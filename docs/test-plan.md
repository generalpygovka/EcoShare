# План перевірок EcoShare (Test Plan)

Цей документ визначає початкові сценарії перевірки та очікувані результати для компонентів системи EcoShare на етапі розробки.

## Початкові сценарії та очікування

| Перевірка / Сценарій | Очікуваний результат | Статус / Примітки |
| :--- | :--- | :--- |
| **Сервер (Health Check)** | Запит до `/api/health` повертає статус `200` та JSON з `status: "ok"`, назвою проєкту та режимом сховища. | Очікує злиття серверного каркаса |
| **Публічний профіль користувача** | Публічне представлення профілю не містить приватних полів (email, контактні дані). | Заплановано для модуля Auth/Users |
| **Стрічка оголошень (Feed)** | Закриті або приховані користувачем записи не відображаються у загальній стрічці. | Очікує реалізації модуля Listings |
| **Пошук оголошень** | Пошуковий запит (наприклад, "ДРИЛЬ") знаходить відповідний предмет незалежно від регістру літер. | Очікує реалізації пошуку |
| **Клієнтський інтерфейс (Mock-дані)** | На головній сторінці відображаються тестові картки (дриль, книга) з правильними станами ("Доступно", "Заброньовано") та адаптивністю під мобільні екрани (360px). | Перевіряється на клієнтській частині |

## Методологія перевірки
- Фактичні результати будуть доповнюватись у міру реалізації відповідних модулів коду.
- Усі сценарії перевіряються через локальний запуск або за допомогою код-рев'ю відповідних Pull Request'ів.
