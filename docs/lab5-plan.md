# План інтеграції EcoShare для лабораторної роботи 5

## Мета

Завершити функціональні компоненти EcoShare, інтегрувати клієнт,
сервер і постійне сховище та перевірити їхню спільну роботу.

## Початковий стан після ЛР4

- Сервер NestJS із модулями Auth/Users і Listings.
- Класи Guest, Resident і Listing.
- Демонстраційні дані в пам’яті серверного процесу.
- Стрічка та текстовий пошук через API.
- React-клієнт, підключений до API.
- Початкова схема Prisma для PostgreSQL.
- 10 автоматичних тестів базової функціональності.
- Перевірки backend, frontend і schema в GitHub Actions.

## Спосіб інтеграції

Локальне середовище розробки та Docker Compose.
Серверна архітектура — модульний моноліт NestJS.

Під час розробки:
- React працює на порту 5173.
- NestJS API працює на порту 3000.
- Vite передає запити /api на NestJS.

## Порядок реалізації

1. Узгодити залежності та формати відповідей клієнта й сервера.
2. Розширити схему Prisma, створити міграції та підключити PostgreSQL.
3. Реалізувати реєстрацію, активацію, авторизацію та профіль.
4. Реалізувати повний сценарій роботи з оголошеннями й фото.
5. Реалізувати бронювання, контакт і сповіщення.
6. Реалізувати скарги, модерацію, блокування та статистику.
7. Перевірити інтегровану систему, оновити README та результати перевірок.
