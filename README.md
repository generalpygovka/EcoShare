# EcoShare

Вебсервіс взаємодопомоги та шерингу для мешканців гуртожитків.

## Поточний етап
ЛР4: поступово створюємо структуру коду, основні класи та мінімальний
демонстраційний сценарій. Перший спринт ще не завершений.

## Архітектура
Модульний моноліт NestJS, React SPA, запланована PostgreSQL через Prisma.
На початковому етапі демонстраційні дані зберігатимуться в пам’яті.

## Команда і запланована відповідальність
- Журавльов Олексій — структура, Prisma, Listings, інтеграція.
- Індевич Олег — сервер, Auth/Users, CI.
- Полєшко Поліна — React та API-клієнт.
- Ільницький Нікіта — сценарії перевірки, тестові дані та тести.

## Командна робота
Окрема гілка для задачі, змістовні коміти, Pull Request та review іншого учасника.
Фактичний внесок і команди запуску доповнюються після реалізації.
